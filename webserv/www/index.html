webserv

HTTP/1.1 server · 42 Madrid · C++98 · poll() · non-blocking

Server: webserv/1.0  |  Config: web.config  |  Port: 8080  |  Keep-alive: 10s timeout

Methods

GET

Static files

Serve files from ./www/ with automatic MIME types.

/index.html / (index.html) /nonexistent → 404
POST

File upload

Upload a file to the server. The request body becomes the file content.


Uploads to /uploads/demo.txt. Copy to /cgi-bin/ for DELETE.
DELETE

File removal

Remove files via DELETE method. Only allowed in /cgi-bin/.


Use Copy to /cgi-bin/ above first, then delete.

Features

GET

Autoindex

Directory listing when no index file is present.

/uploads/ /files/
GET

Redirects

301 Moved Permanently via return directive.

/old_path → /uploads
CGI

CGI scripts

Python and Shell scripts executed via fork+execve.

test.py hello.sh form.py?name=42 timeout.py → 504 error.py → 500
Error

HTTP errors

Built-in and custom error pages.

404 Not Found 405 Method Not Allowed 500 Internal 504 Gateway Timeout
Encoding

Chunked transfer

Server receives Transfer-Encoding: chunked requests.

CHUNK POST to file

Try: curl -X POST --data-binary @file http://localhost:8080/upload

Connection

Keep-alive

Reuse TCP connections for multiple requests (10s idle timeout).

Try: curl -H "Connection: keep-alive" http://localhost:8080/

Virtual Hosts

Virtual hosts

Route by Host header — server blocks matched by server_name.

Try: curl -H "Host: example.com" http://localhost:8080/

Validation

Request limits

Configurable client_max_body_size (default 10 KB).

413 Content Too Large
20000 bytes > 10000 limit

Quick test (terminal)

# Serve static
curl http://localhost:8080/index.html

# POST upload
curl -X POST -d "hello world" http://localhost:8080/hello.txt

# DELETE
curl -X DELETE http://localhost:8080/cgi-bin/hello.txt

# CGI
curl http://localhost:8080/cgi-bin/test.py

# Keep-alive + multiple requests
curl -H "Connection: keep-alive" http://localhost:8080/ http://localhost:8080/index.html

# Chunked POST
printf "5\r\nHello\r\n0\r\n\r\n" | curl -X POST -H "Transfer-Encoding: chunked" \
  --data-binary @- http://localhost:8080/chunked.txt

# Autoindex
curl http://localhost:8080/uploads/

# Custom error page (server 2)
curl -H "Host: example.com" http://localhost:8080/nonexistent

# 408 Request Timeout (open connection, send partial headers, wait)
python3 -c "
import socket; s=socket.socket(); s.connect(('localhost',8080));
s.send(b'GET / HTTP/1.1\r\nHost: localhost\r\n'); import time; time.sleep(65);
s.send(b'\r\n'); print(s.recv(1024).decode(errors='replace').split('\r\n')[0])"
