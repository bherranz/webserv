Overview

Server: webserv/1.0  |  Config: web.config  |  Port: 8080  |  Keep-alive: 10s timeout  |  Client timeout: 60s

webserv is an HTTP/1.1 server written in C++98. It serves static files, executes CGI scripts, handles file uploads, and more — all driven by a single poll() event loop.

Navigate using the tabs above to explore each feature.

HTTP Methods

Static files

Files from ./www/ served with automatic MIME types.

/index.html / (index.html) /nonexistent → 404
POST

Upload via body

Send raw text as the request body to create a file.


See Upload tab for file picker upload.
DELETE

File removal

Delete files via DELETE. Allowed in /uploads and /cgi-bin.

File Upload

Select a file from your computer and upload it to the server. The server supports both raw body uploads and multipart/form-data (standard HTML file picker).

Upload a file

Files are stored in ./www/uploads/. You can view them via /uploads/ autoindex and delete them from the Methods tab.

Upload via curl

# Raw body
curl -X POST -d "hello world" http://localhost:8080/uploads/test.txt

# File upload (multipart)
curl -F "file=@document.pdf" http://localhost:8080/uploads/document.pdf

# Chunked
printf "5\r\nHello\r\n0\r\n\r\n" | curl -X POST -H "Transfer-Encoding: chunked" \
  --data-binary @- http://localhost:8080/uploads/chunked.txt

Server Features

Autoindex

Directory listing when no index file is present.

/uploads/ /files/

Redirects

301 Moved Permanently via return directive.

/old_path → /uploads

Error pages

Built-in and custom error pages (error_page directive).

404 500 504

Keep-alive

Reuse TCP connections for multiple requests (configurable timeout).

Try: curl -H "Connection: keep-alive" http://localhost:8080/ http://localhost:8080/index.html

Virtual hosts

Route by Host header — server blocks matched by server_name.

Try: curl -H "Host: example.com" http://localhost:8080/ (server 2 on port 8082)

Timeouts

Configurable per-server client_timeout (default 60s) and keepalive_timeout (default 10s). 408 returned on timeout.

Chunked encoding

Server accepts Transfer-Encoding: chunked and un-chunks body before passing to CGI or saving to disk.

Request limits

client_max_body_size limits request body size (default 10 KB).
